## Calendar automation

Calendar automation is intentionally outside this plugin. Context Nine does not run a background Google Calendar timer or expose calendar sync settings. Personal Vault agents use the `gws-custom-calendar` skill and call the Google Workspace CLI directly for explicit events and time blocks.
